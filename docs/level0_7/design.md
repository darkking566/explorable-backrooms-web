# Level 0.7「憶域」— 已核准設計

使用者於 2026-11-06 確認聊天中的規劃並授權製作。這是既有 Three.js 遊戲的新增關卡。

## 核心與首版範圍

六個可往返年代區：現代、早期電氣、華麗高廳、中世紀、羅馬、埃及。探索＋輕度生存；水量、疲勞、時代物件與睡眠位移；四種古老實體、局部火災、完整原文檔案、地圖與正常步行出入口。

建築尺度、結構、材質和聲音共同表現年代變化。主路連接六區，各區有側室與環路。閱讀、地圖及暫停時凍結遊戲時間。已讀紀錄在失敗後保留。睡眠落點必須可站立且可返回入口。

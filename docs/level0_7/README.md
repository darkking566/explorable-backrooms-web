# Level 0.7「憶域」試玩

重新整理原本的遊戲頁面。按 **M → Level 0.7**，將小人拖到綠色可落地區域，再點擊畫面開始。正常步行入口也已接入：在 Level 0 地圖搜尋「憶域通路」，前往西側有 N.T.G. 紙條的通道。

## 操作

- WASD／方向鍵移動，Shift 奔跑，滑鼠環顧。
- E 調查、讀檔、取得時代物件，或在有遮蔽物的休息處睡眠。
- J 開啟檔案目錄。調查資料隨身攜帶，其餘文件在場景中找到後解鎖，之後可重讀。
- F 就地休息。若人在休息棚下，會套用遮蔽條件；露宿的位移風險較高。睡眠不會補水。
- M 地圖，Esc 暫停。讀文件、地圖、暫停期間不消耗生存數值。

沿著燈具與建築愈來愈現代的方向返回，就能走回 Level 0。一次攜帶一件年代物件，拾取新物件會替換選擇；它只影響睡眠結果，不保證目的地。失敗會結束本趟探索、恢復起點與補給，保留已讀檔案。已讀紀錄儲存在目前瀏覽器的本機儲存空間。

## 內容

六區依序為現代、早期電氣、華麗高廳、中世紀、羅馬與埃及。四類實體為古老獵犬、畸形無面靈、古老窃皮者、咆哮者。可讀內容包含三頁完整檔案、七個年代分頁（含未證實的前人類理論）、註腳、補充修訂、作者說明與圖像授權。

史前地區尚未作為已確認場景製作；爆破歷史 Level 1、飛入 Level 6 的玩法屬後續範圍，相關原文保留在檔案裡。

## 驗證工具

`node scripts/check-level07-static.mjs` 檢查完整載入順序的 JavaScript 解析、檔案與來源內容。

`python scripts/check-level07.py` 使用這台電腦已安裝的 Playwright／Chrome，開啟獨立瀏覽器與本機暫時伺服器，輸出至 `docs/level0_7/evidence/`。不控制或修改使用者原本的 Chrome 視窗。比較畫面效能時須同時看解析度、繪圖比例、顯示卡與測點；短樣本不能代表長時間或所有路線。

`python scripts/sync-level07-source.py` 重新下載指定維基的三頁公開原文，建置不執行原站腳本的本機閱讀副本。這是主動更新來源的工具；一般遊玩不需執行它。

使用者親自試玩、長時間平衡與主觀音效效果仍需另外驗收。
